00 · SETUP FUNDAMENTOS · EMPIEZA AQUÍ
La base común de toda la serie: léela antes de cualquier máquina.
Setup del entorno y VPN, metodología, los reflejos que se repiten máquina tras máquina, el arsenal explicado por propósito (cuándo usar cada herramienta, no la sintaxis), un glosario de conceptos base y un checklist de arranque. El andamiaje que une Cap, Knife y Forest.
METODOLOGÍA ARSENAL GLOSARIO
EMPIEZA AQUÍ
CAP HTB · EASY · LINUX
Guía para principiantes: de la conexión VPN hasta root, razonando cada decisión.
Cadena completa: reconocimiento con nmap → IDOR para acceder a un PCAP ajeno → credenciales FTP en texto plano en Wireshark → password reuse hacia SSH → escalada por cap_setuid en Python con GTFOBins. Pensada para quien resuelve su primera máquina.
IDOR PCAP PRIVESC
LEER GUÍA
KNIFE HTB · EASY · LINUX
La #2 de la serie: de una cabecera olvidada a root, con reverse shell y sudo.
Cadena completa: nmap → fingerprinting con curl -I que revela PHP 8.1.0-dev → backdoor zerodiumvar_dump vía cabecera User-Agentt → reverse shell sin credenciales → escalada por sudo knife (Chef/Ruby) con GTFOBins. Extiende lo aprendido en Cap.
RCE REV SHELL SUDO
LEER GUÍA
FOREST HTB · EASY · WINDOWS · AD
La #3: primera Active Directory. De la enumeración anónima a Domain Admin.
Ataque de dominio completo: fingerprint de DC → enumeración anónima por SMB/LDAP → AS-REP Roasting + crack con john → foothold por WinRM → BloodHound mapea el camino → abuso de ACLs (GenericAll/WriteDacl) → DCSync → Pass-the-Hash como Administrator. Cambia de paradigma respecto a las Linux.
AS-REP BLOODHOUND DCSYNC
LEER GUÍA
VACCINE HTB · VERY EASY · LINUX
La #4: primera SQL injection, con un capítulo entero de troubleshooting de shells.
Cadena de ocho eslabones: FTP anónimo → cracking de ZIP con zip2john → hash MD5 en el código → SQL injection con sqlmap --os-shell → reverse shell → credencial en config → escalada por sudo vi. Incluye lo que ningún walkthrough cuenta: cómo estabilizar el TTY y depurar cuando la shell no coopera.
SQLI TTY SUDO
LEER GUÍA
SAUNA HTB · EASY · WINDOWS · AD
La #5: segunda Active Directory. Mismo destino que Forest, camino distinto.
De un banco ficticio a Domain Admin: usuarios desde la web (nombres de empleados → username) → AS-REP Roasting → foothold por WinRM → autologon en el registro (credenciales en texto claro) → DCSync directo → Pass-the-Hash. Refuerza Forest con dos técnicas nuevas.
AS-REP AUTOLOGON DCSYNC
LEER GUÍA
