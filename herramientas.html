Recon & Enum

nmap
HerramientaEnlace a esta herramienta

Escáner de puertos y servicios; el primer barrido de todo host.

Cuándo usarla

Al empezar cualquier objetivo, para saber qué corre y por dónde entrar.

Documentación de nmap

ffuf / wfuzz
HerramientaEnlace a esta herramienta

Fuzzers HTTP rápidos para directorios, parámetros y virtual hosts.

Cuándo usarla

Descubrir rutas ocultas, forzar tokens débiles o enumerar vhosts.

Documentación de ffuf / wfuzz

wpscan
HerramientaEnlace a esta herramienta

Escáner específico de WordPress: usuarios, plugins y temas vulnerables.

Cuándo usarla

Cuando el objetivo corre WordPress y buscas un punto de entrada.

Documentación de wpscan

smbmap / nxc
HerramientaEnlace a esta herramienta

NetExec (nxc) habla SMB, LDAP, WinRM y MSSQL desde una sola herramienta; smbmap lista shares.

Cuándo usarla

Enumerar recursos, validar credenciales en masa y ejecutar en toda una red.

Documentación de smbmap / nxc

BloodHound
HerramientaEnlace a esta herramienta

BloodHound CE grafica AD y revela rutas de privilegio entre usuarios, grupos y hosts; aquí se usa el recolector bloodhound-ce-python, compatible con CE.

Cuándo usarla

Tras conseguir una credencial de dominio, para analizar relaciones y permisos. Registra las versiones de CE y del recolector; la cobertura depende de los permisos y servicios accesibles. La URL y las credenciales iniciales se obtienen del despliegue instalado, no se presuponen.

Documentación de BloodHound

Web Exploitation

Burp Suite
HerramientaEnlace a esta herramienta

Proxy interceptor para inspeccionar y manipular tráfico HTTP a mano.

Cuándo usarla

Analizar peticiones, Repeater/Intruder y afinar payloads.

Documentación de Burp Suite

sqlmap
HerramientaEnlace a esta herramienta

Automatiza detección y explotación de inyección SQL, incluida la ciega.

Cuándo usarla

Confirmar una SQLi y volcar bases de datos sin escribir el payload a mano.

Documentación de sqlmap

php://filter
HerramientaEnlace a esta herramienta

Wrapper de PHP que lee el código fuente de un archivo en base64.

Cuándo usarla

En un LFI, para leer la lógica del servidor antes de escalar a RCE.

Documentación de php://filter

INTO OUTFILE
HerramientaEnlace a esta herramienta

Directiva SQL que escribe el resultado de una consulta en el sistema de archivos.

Cuándo usarla

En una SQLi con permiso FILE, para plantar una web shell en el webroot.

Documentación de INTO OUTFILE

Active Directory

NetExec (nxc)
HerramientaEnlace a esta herramienta

Ejecución y enumeración multiprotocolo (SMB, LDAP, WinRM, MSSQL, RDP).

Cuándo usarla

La que más uso en AD: shares, kerberoasting, spraying, DPAPI, pass-the-hash.

Documentación de NetExec (nxc)

bloodyAD
HerramientaEnlace a esta herramienta

Lee y modifica objetos de AD (ACLs, atributos, membresías) desde Linux.

Cuándo usarla

Abusar de permisos: GenericAll, WriteSPN, add groupMember, set password, RBCD.

Documentación de bloodyAD

Impacket
HerramientaEnlace a esta herramienta

Suite de scripts Python para los protocolos de Windows (secretsdump, getST, GetUserSPNs, ticketer, mssqlclient, etc.).

Cuándo usarla

Casi todo en AD: DCSync, delegación, tickets Kerberos, MSSQL remoto.

Documentación de Impacket

Rubeus
HerramientaEnlace a esta herramienta

Manipulación de Kerberos en Windows (monitor, tgtdeleg, asktgt, S4U).

Cuándo usarla

Cosechar TGTs vía delegación/coerción o abusar de S4U.

Documentación de Rubeus

certipy-ad
HerramientaEnlace a esta herramienta

Enumera y explota ADCS: plantillas vulnerables, Shadow Credentials, ESC1-ESC9.

Cuándo usarla

Cuando hay una CA en juego o puedes escribir msDS-KeyCredentialLink.

Documentación de certipy-ad

Responder + ntlmrelayx
HerramientaEnlace a esta herramienta

Responder envenena LLMNR/NBT-NS para capturar auths; ntlmrelayx las relayea.

Cuándo usarla

Capturar NTLMv2 o evaluar relay en un laboratorio. Para LDAPS, revisa channel binding y los permisos de la identidad relayada; SMB signing:False y MAQ por sí solos no demuestran que la cadena funcione.

Documentación de Responder + ntlmrelayx

mimikatz
HerramientaEnlace a esta herramienta

Extrae credenciales de memoria y secretos de LSA (incluidas trust keys).

Cuándo usarla

Volcar LSASS, claves de confianza inter-forest o pass-the-ticket.

Documentación de mimikatz

Credenciales & Cracking

hashcat
HerramientaEnlace a esta herramienta

Crackeador de hashes acelerado por GPU; soporta cientos de formatos.

Cuándo usarla

Romper hashes de Kerberoasting (13100), NetNTLMv2 (5600), AS-REP (18200), NTLM.

Documentación de hashcat

john
HerramientaEnlace a esta herramienta

John the Ripper: crackeo versátil, ideal para formatos con *2john.

Cuándo usarla

Claves SSH, Ansible Vault, ZIP y hashes que hashcat no cubre cómodo.

Documentación de john

pypykatz
HerramientaEnlace a esta herramienta

Reimplementación en Python de mimikatz para parsear dumps offline.

Cuándo usarla

Extraer credenciales de un minidump de LSASS sin ejecutar nada en el host.

Documentación de pypykatz

secretsdump
HerramientaEnlace a esta herramienta

Vuelca hashes de SAM/LSA/NTDS local o remotamente (parte de Impacket).

Cuándo usarla

Tras leer las hives (SeBackup) o al hacer DCSync contra el DC.

Documentación de secretsdump

gMSADumper
HerramientaEnlace a esta herramienta

Recupera material de la contraseña administrada de gMSA cuando la identidad autenticada tiene autorización efectiva para obtener msDS-ManagedPassword.

Cuándo usarla

Cuando controlas un principal autorizado a recuperar la contraseña de una gMSA. Leer la lista de principales autorizados no equivale a poder recuperar el secreto.

Documentación de gMSADumper

LaZagne
HerramientaEnlace a esta herramienta

Cosecha credenciales guardadas por apps locales (navegadores, chats).

Cuándo usarla

En un host comprometido, para recolectar accesos a otros sistemas.

Documentación de LaZagne

Privesc & Post-Explotación

GodPotato / SigmaPotato
HerramientaEnlace a esta herramienta

Abusan de SeImpersonatePrivilege para duplicar un token SYSTEM.

Cuándo usarla

Tienes RCE como cuenta de servicio con SeImpersonate (IIS, MSSQL).

Documentación de GodPotato / SigmaPotato

GTFOBins
HerramientaEnlace a esta herramienta

Catálogo de binarios Unix que escalan privilegios vía sudo/SUID.

Cuándo usarla

Al revisar 'sudo -l' o SUIDs: buscar un escape de shell conocido.

Documentación de GTFOBins

evil-winrm
HerramientaEnlace a esta herramienta

Shell interactiva sobre WinRM con soporte de pass-the-hash y Kerberos.

Cuándo usarla

Acceso estable a un host Windows con credenciales, hash o ticket.

Documentación de evil-winrm

comsvcs.dll
HerramientaEnlace a esta herramienta

DLL firmada por Microsoft cuyo export MiniDump vuelca LSASS (LOLBin).

Cuándo usarla

Extraer LSASS sin subir herramientas marcadas por el antivirus.

Documentación de comsvcs.dll

Pivoting & Túneles

Ligolo-ng
HerramientaEnlace a esta herramienta

Crea un túnel con interfaz TUN que enruta redes internas no alcanzables.

Cuándo usarla

Pivotar a segmentos o bosques no enrutables desde el host comprometido.

Documentación de Ligolo-ng

chisel
HerramientaEnlace a esta herramienta

Túnel TCP/UDP sobre HTTP, útil para port-forwarding rápido.

Cuándo usarla

Reenviar un puerto interno hacia tu máquina cuando Ligolo es excesivo.

Documentación de chisel

Inveigh
HerramientaEnlace a esta herramienta

Equivalente de Responder para Windows: captura NTLMv2 desde dentro.

Cuándo usarla

Ya tienes un host Windows interno y quieres capturar hashes del segmento.

Documentación de Inveigh

SpoolSample / PetitPotam
HerramientaEnlace a esta herramienta

Disparan coerción de autenticación (MS-RPRN / MS-EFSR) contra un host.

Cuándo usarla

Forzar la cuenta de máquina de un DC a autenticarse contra tu listener.

Documentación de SpoolSample / PetitPotam

C2 & Evasión

Sliver
HerramientaEnlace a esta herramienta

Framework de Command & Control open source con implants multiplataforma.

Cuándo usarla

Operaciones más largas que necesitan sesiones persistentes y post-explotación estructurada.

Documentación de Sliver

Havoc
HerramientaEnlace a esta herramienta

Framework C2 moderno con demonio evasivo y perfiles configurables.

Cuándo usarla

Cuando necesitas un agente más sigiloso frente a EDR que un Meterpreter.

Documentación de Havoc

SigmaPotato
HerramientaEnlace a esta herramienta

Variante de potato con carga en memoria y opciones de evasión (p.ej. RC4).

Cuándo usarla

SeImpersonate en un host con EDR que ya marca GodPotato.

Documentación de SigmaPotato

AI / LLM Red Team

Prompt injection
HerramientaEnlace a esta herramienta

Instrucciones maliciosas (directas o incrustadas en datos) que redirigen a un LLM.

Cuándo usarla

Cuando un agente LLM procesa entrada no confiable o expone tools.

Documentación de Prompt injection

PyTorch
HerramientaEnlace a esta herramienta

Framework de ML para cargar modelos y construir ataques adversariales locales.

Cuándo usarla

Optimizar perturbaciones (C&W, JSMA) contra un modelo .pth descargado.

Documentación de PyTorch

MCP abuse
HerramientaEnlace a esta herramienta

Explotación de tools de un servidor MCP (command injection, acceso indebido).

Cuándo usarla

El servidor expone una tool cuyo argumento se concatena a un shell. El nombre export del ejemplo es ilustrativo: consulta las herramientas disponibles y su inputSchema en el laboratorio autorizado.

Documentación de MCP abuse
