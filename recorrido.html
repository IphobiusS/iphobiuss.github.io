CUATRO PARADAS · LECTURA ESTIMADA DE 90 SEGUNDOS

Soy Sebastián, Pentester Junior en Santiago. Investigo seguridad web, Active Directory e IA/LLM, y construyo herramientas para documentar el trabajo con claridad. Este recorrido reúne mi criterio técnico, un caso HTTP propio, una retrospectiva de Active Directory y un resultado de reporting.

Los tiempos son orientativos: puedes detenerte y abrir cada caso a tu ritmo. Con JavaScript, el raíl señala la sección que estás viendo; no mide tiempo ni registra lectura completada. Los cuatro enlaces funcionan también sin JavaScript.

  1. 01Mi criterio
  2. 02Seguridad web
  3. 03Active Directory
  4. 04Reporting

  1. Lectura estimada: 20 s

    Qué me importa

    Separar lo observado de lo supuesto. Un resultado tiene valor cuando puedo explicar su alcance, la evidencia y la decisión siguiente.

    Leer mi metodología

  2. Lectura estimada: 25 s

    De un fallo propio a su retest

    Construí una API local con un fallo deliberado: una sesión puede leer y modificar el informe de otra identidad. El parche comprueba el propietario en el servidor. El retest compara ambas identidades y confirma con una lectura posterior si cada escritura cambió el objeto.

    Comparar la evidencia HTTPTambién: revocación de sesionesRetrospectiva de Cap

  3. Lectura estimada: 25 s

    Una decisión en Active Directory

    Forest: una cuenta de servicio y relaciones de permisos explican la escalada. DCSync permite replicar material de autenticación; no demuestra pertenencia a Domain Admins.

    Abrir el expediente de Forest

  4. Lectura estimada: 20 s

    Cómo presento el resultado

    report-gen convierte hallazgos, evidencias y decisiones en entregas revisables. Banco Lumbre permite explorar su aplicación al riesgo empresarial con datos completamente ficticios.

    Ver tres tareas de reportingLeer la simulación bancaria
El caso HTTP es una aplicación propia con datos sintéticos y solicitudes locales registradas; el explorador no ejecuta pruebas nuevas. Cap y Forest son retrospectivas de laboratorios HTB. Banco Lumbre es una simulación ficticia. Ninguno representa un encargo profesional.
